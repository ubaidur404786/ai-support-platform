# Deleting your workspace

Deleting a workspace is permanent and cannot be undone. Only the workspace owner can do it, from Settings > Advanced > Delete workspace.

Before deletion we ask you to type the workspace name to confirm. All tickets, documents, members and integrations are removed within 30 days, and backups are purged within 90 days.

If you only want to leave a workspace that someone else owns, use Profile > Leave workspace instead; the workspace itself is not affected.
