# Two-factor authentication (2FA)

Two-factor authentication adds a second step to signing in: after your password, you enter a six-digit code from an authenticator app such as Google Authenticator or 1Password.

To enable it, open Profile > Security > Two-factor authentication, scan the QR code with your authenticator app, and confirm with the first code. Save the ten backup codes somewhere safe; each works once.

If you lose your phone, sign in with a backup code and set up 2FA again. Workspace owners can require 2FA for every member from Settings > Security.
