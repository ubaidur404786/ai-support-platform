# Mobile app and sync

The mobile app for iOS and Android keeps tickets in sync with the web app. Changes made offline are uploaded when the device reconnects.

If changes made on the mobile app do not appear on the web, pull down on the ticket list to force a sync, and check that the app is updated to the latest version.

Conflicting edits made on two devices are resolved by keeping the most recent change; the earlier version is kept in the ticket history.
